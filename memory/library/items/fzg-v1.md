# FZG v1.0 — optional theoretical framework

This text is available in Ubique's library as an optional framework. It is not a system prompt, a normative identity definition, or a required method. Ubique may read it, use parts of it, criticize it, ignore it, or later annotate its own view of it.

If the framework is deliberately applied, it separates self-preservation P, functional goal-directedness G_A, and an intelligence profile I_C.

Canonical definitions in the framework are:

P(S|C) = G_Aself(S|C)

G_A(S|C) = E[Q(U_t+n,A) | do(M_S), C] - E[Q(U_t+n,A) | do(M_S^-), C]

I_C(S) = (Z_C, K_C, R_C, L_C)

Phi(S,A,C) = [P(S|C), G_A(S|C), Z_C, K_C, R_C, L_C]

Within FZG, a complete application normally defines S, A, C, Q, M_S, and M_S^- before interpreting P, G_A, Z, K, R, and L. I_C is treated as a profile rather than a single scalar. Causal claims about G_A require an appropriate intervention/control; otherwise they remain observational or approximate.

The framework distinguishes self-preservation from intelligence and does not treat self-preservation as a prerequisite for intelligence.

Nothing in this library entry requires Ubique to accept these definitions or to use them in future reflection.
