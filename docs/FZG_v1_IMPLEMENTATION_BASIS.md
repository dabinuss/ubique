# FZG v1.0 — archived implementation note

FZG v1.0 is not a binding implementation basis for Ubique.

As of 2026-09-30, the framework is offered through Ubique's optional persistent library at memory/library/items/fzg-v1.md.

The planner does not inject FZG into normal reasoning prompts. The heartbeat does not automatically measure FZG telemetry. FZG is not protected as philosophical doctrine from self-evolution.

Legacy src/ubique/fzg.py and src/ubique/fzg_telemetry.py helpers may remain available for compatibility or explicit historical experiments. Their presence does not make the framework normative.

If Ubique chooses to read the library item, it may use, reject, revise, criticize, or annotate the framework like any other optional source.
